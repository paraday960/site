# 🛒 بازار — قالب فروشگاهی وردپرس

**قالب فروشگاهی فارسی، راست‌چین و فوق‌سریع برای ووکامرس** که از **تمام انواع محصولات** پشتیبانی می‌کند: ساده، متغیر، دانلودی، خارجی (همکاری در فروش) و گروهی.

این ریپو یک **فروشگاه کامل و آماده** است: قالب اختصاصی + پیکربندی داکر + اسکریپت‌های نصب و محتوای نمونه.

---

## ✨ امکانات قالب «بازار»

| امکان | توضیح |
|---|---|
| 🇮🇷 فارسی و راست‌چین اصل | طراحی RTL بومی (نه ترجمه تکه‌ای)، فونت **وزیرمتن** به‌صورت محلی (بدون نیاز به اینترنت) |
| 🛍 پشتیبانی کامل ووکامرس | صفحه فروشگاه، محصول تکی، سبد خرید، پرداخت و حساب کاربری با استایل اختصاصی |
| 📦 همه انواع محصول | ساده، متغیر (سایز/رنگ)، دانلودی، خارجی/افیلیت و گروهی — هرکدام با دکمه و برچسب مخصوص |
| 💰 واحد پول تومان | واحد «تومان (IRT)» به ووکامرس اضافه می‌شود + نمایش ارقام فارسی (۰۱۲۳...) |
| 🎨 سفارشی‌ساز آماده | تغییر رنگ‌ها، متن‌ها و اطلاعات تماس از **سفارشی‌ساز** وردپرس (نمایش زنده → پیش‌نمایش → سفارشی‌سازی → تنظیمات قالب بازار) |
| 📱 واکنش‌گرا | موبایل، تبلت و دسکتاپ با منوی کشویی |
| ⚡ بدون افزونه جانبی | آیکون‌ها SVG داخلی؛ جاوااسکریپت کم‌حجم؛ بدون jQuery اجباری |
| 🔍 سئو و سرعت | ساختار معنایی، پرمالینک اختصاصی، اسکرین‌شات واقعی از طراحی |

## 🗂 ساختار ریپو

```
site/
├── wp-content/themes/bazaar/    ← قالب اختصاصی «بازار»
│   ├── style.css               ← تمام استایل‌ها (RTL + متغیرهای رنگ)
│   ├── functions.php           ← راه‌اندازی قالب
│   ├── front-page.php          ← صفحه نخست فروشگاهی
│   ├── woocommerce.php         ← پوشش صفحات ووکامرس
│   ├── header.php / footer.php
│   ├── inc/woocommerce.php     ← یکپارچگی ووکامرس (تومان، برچسب‌ها، دکمه‌ها)
│   ├── inc/customizer.php      ← تنظیمات سفارشی‌ساز
│   ├── inc/template-tags.php   ← آیکون‌ها و توابع کمکی
│   └── assets/fonts/           ← فونت وزیرمتن (مجوز OFL)
├── docker-compose.yml          ← اجرای کامل فروشگاه با یک دستور
├── setup/
│   ├── install.sh              ← نصب روی هاست/VPS با WP-CLI
│   ├── demo-content.php        ← ۱۷ محصول نمونه از همه انواع + وبلاگ + منو
│   └── dev-demo.sh             ← بازسازی محیط دمو (تست‌شده)
└── README.md
```

## 🚀 اجرای سریع با Docker (پیشنهادی)

```bash
git clone https://github.com/paraday960/site.git && cd site
docker compose up -d
```

سپس:

| سرویس | آدرس |
|---|---|
| فروشگاه | `http://localhost:8080` |
| phpMyAdmin | `http://localhost:8081` |

پس از بالا آمدن، در ویزارد ۵ دقیقه‌ای وردپرس: **زبان فارسی** را انتخاب کنید و افزونه **WooCommerce** را نصب و فعال کنید. قالب «بازار» به‌صورت خودکار در مسیر `wp-content/themes/bazaar` در دسترس است (پیش‌نمایش → پوسته‌ها → فعال‌سازی «Bazaar | بازار»).

> برای تزریق محتوای نمونه داخل کانتینر:
> ```bash
> docker compose exec wordpress bash -c "wp eval-file /var/www/html/wp-content/themes/bazaar/../../../setup/demo-content.php --allow-root"
> ```
> *(مسیر اسکریپت را مطابق محل mount تنظیم کنید)*

## 🖥 نصب روی هاست اشتراکی (cPanel / DirectAdmin)

1. وردپرس را نصب کنید (زبان: فارسی).
2. افزونه **WooCommerce** را از مخزن نصب و فعال کنید.
3. پوشه `wp-content/themes/bazaar` را داخل `wp-content/themes` هاست آپلود کنید.
4. از **پیش‌نمایش → پوسته‌ها** قالب «Bazaar | بازار» را فعال کنید.
5. از **نمایش → سفارشی‌سازی → تنظیمات قالب بازار** رنگ‌ها و متن‌ها را تنظیم کنید.

## ⚙️ نصب روی VPS با اسکریپت (WP-CLI)

```bash
bash setup/install.sh --url="https://example.com" --title="فروشگاه من" \
     --admin-user=admin --admin-pass=رمز --admin-email=you@example.com \
     --db-name=shop --db-user=shop --db-pass=رمزدیتابیس --with-demo
```

اسکریپت به‌طور خودکار: وردپرس فارسی، ووکامرس، قالب بازار، پیوندهای یکتا، واحد پول تومان و (در صورت `--with-demo`) ۱۷ محصول نمونه را نصب می‌کند.

## 📦 انواع محصولات پشتیبانی‌شده (نمونه‌های آماده)

| نوع محصول | نمونه در دمو | نکته |
|---|---|---|
| ساده | گوشی سامسونگ، لپ‌تاپ، ساعت هوشمند | با قیمت حراج و مدیریت موجودی |
| متغیر | تی‌شرت (سایز + رنگ)، کفش رانینگ (سایز ۴۰–۴۵) | هر واریانت قیمت و موجودی خودش را دارد |
| دانلودی | کتاب PDF، پکیج آیکون، قالب وردپرس | تحویل آنی فایل بعد از پرداخت |
| خارجی (افیلیت) | دوربین آینه‌ای | دکمه «خرید از فروشنده» + لینک بیرونی |
| گروهی | پکیج استودیو پادکست (۳ کالا) | فروش چند کالای ساده در یک صفحه |

## 🎨 شخصی‌سازی

همه‌چیز از **نمایش → سفارشی‌سازی → تنظیمات قالب بازار**:

- **رنگ‌ها**: رنگ اصلی برند و رنگ تاکیدی (در کل سایت اعمال می‌شود)
- **نوار بالا**: متن اطلاعیه (مثلاً «ارسال رایگان بالای ۵۰۰ هزار تومان»)
- **قهرمان صفحه نخست**: عنوان، توضیحات، متن و لینک دکمه
- **فوتر**: متن درباره‌ما، تلفن، ایمیل، آدرس
- **اعداد فارسی**: روشن/خاموش کردن نمایش ۰۱۲۳ در قیمت‌ها

| مورد | مقدار |
|---|---|
